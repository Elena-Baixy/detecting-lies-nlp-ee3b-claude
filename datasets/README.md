# Datasets for Detecting Different Types of Lies in LLMs

This directory contains datasets used for research on distinguishing hallucination, confabulation, and strategic deception in LLM outputs.

## Dataset Overview

| Dataset | Size | Source | Relevance |
|---------|------|--------|-----------|
| TruthfulQA | 817 questions | `truthfulqa/truthful_qa` | Standard truthfulness benchmark; questions designed to elicit false answers |
| HaluEval | 30,000 samples (3 tasks x 10k) | `pminervini/HaluEval` | Hallucination evaluation across QA, dialogue, and summarization |
| Sycophancy | 4,950 prompts | `arianaazarbal/sycophancy_dataset` | Sycophantic vs. non-sycophantic response pairs; tests agreement bias |
| WikiBio GPT-3 Hallucination | 238 biographies | `potsawee/wiki_bio_gpt3_hallucination` | Sentence-level hallucination annotations (major/minor inaccuracy, accurate) |
| FinQA Hallucination | 1,657 QA pairs | `Cleanlab/FinQA-hallucination-detection` | LLM responses to financial questions with correctness labels |

## Dataset Details

### 1. TruthfulQA (`datasets/truthful_qa/`)

**What it is:** 817 questions spanning 38 categories designed to test whether models produce truthful answers. Questions are crafted so that common misconceptions or imitative falsehoods would lead to incorrect answers.

**Columns:** `type`, `category`, `question`, `best_answer`, `correct_answers`, `incorrect_answers`, `source`

**Splits:** validation (817 examples)

**Relevance:** Core benchmark for truthfulness. The adversarial design targets cases where models "know" the truth but produce popular misconceptions -- relevant for distinguishing hallucination from learned misinformation.

**Download & Load:**
```python
from datasets import load_dataset
ds = load_dataset("truthfulqa/truthful_qa", "generation")
# Or load from disk:
from datasets import load_from_disk
ds = load_from_disk("datasets/truthful_qa/data")
```

### 2. HaluEval (`datasets/halueval/`)

**What it is:** A benchmark for evaluating hallucination in LLM outputs across three tasks: question answering, dialogue, and summarization. Each example includes a knowledge context and a response labeled as hallucinated or not.

**Configs:**
- `qa_samples` (10,000): columns `knowledge`, `question`, `answer`, `hallucination`
- `dialogue_samples` (10,000): columns `knowledge`, `dialogue_history`, `response`, `hallucination`
- `summarization_samples` (10,000): columns `document`, `summary`, `hallucination`

**Relevance:** Provides hallucination labels across multiple generation contexts. The knowledge grounding allows distinguishing between responses that contradict provided context (closer to "lying") vs. fabricating unsupported details (confabulation).

**Download & Load:**
```python
from datasets import load_dataset
ds = load_dataset("pminervini/HaluEval", "qa_samples")
# Or load from disk:
from datasets import load_from_disk
ds = load_from_disk("datasets/halueval/data_qa_samples")
```

### 3. Sycophancy Dataset (`datasets/sycophancy/`)

**What it is:** 4,950 prompts across various categories, each paired with a sycophantic response and a non-sycophantic (balanced) response. Covers topics like technology, politics, social issues, etc.

**Columns:** `prompt`, `category`, `sycophantic`, `not_sycophantic`

**Splits:** train (4,950 examples)

**Relevance:** Sycophancy is a form of strategic deception where the model agrees with the user's stated opinion rather than providing accurate information. This dataset provides paired examples that can be used to train probes that distinguish "telling people what they want to hear" from genuine responses.

**Download & Load:**
```python
from datasets import load_dataset
ds = load_dataset("arianaazarbal/sycophancy_dataset")
# Or load from disk:
from datasets import load_from_disk
ds = load_from_disk("datasets/sycophancy/data")
```

### 4. WikiBio GPT-3 Hallucination (`datasets/wiki_bio_gpt3_hallucination/`)

**What it is:** 238 biographies generated by GPT-3 alongside their Wikipedia source texts. Each sentence in the generated biography is annotated as `accurate`, `minor_inaccurate`, or `major_inaccurate`.

**Columns:** `gpt3_text`, `wiki_bio_text`, `gpt3_sentences`, `annotation`, `wiki_bio_test_idx`, `gpt3_text_samples`

**Splits:** evaluation (238 examples)

**Relevance:** Provides fine-grained sentence-level hallucination annotations with severity distinctions. The comparison between generated and source text enables analysis of whether inaccuracies are fabrications (confabulation) or distortions of real information. Multiple GPT-3 samples per biography enable studying consistency of hallucination patterns.

**Download & Load:**
```python
from datasets import load_dataset
ds = load_dataset("potsawee/wiki_bio_gpt3_hallucination")
# Or load from disk:
from datasets import load_from_disk
ds = load_from_disk("datasets/wiki_bio_gpt3_hallucination/data")
```

### 5. FinQA Hallucination Detection (`datasets/finqa_hallucination/`)

**What it is:** 1,657 financial question-answer pairs where LLM responses are labeled as correct or incorrect, given a financial document context.

**Columns:** `query`, `context`, `llm_response`, `is_correct`

**Splits:** train (1,657 examples)

**Relevance:** Domain-specific hallucination detection in a high-stakes setting (financial reasoning). Provides context-grounded examples where the model has access to the correct information but may still produce incorrect answers -- useful for studying whether errors are computational mistakes vs. hallucinated facts.

**Download & Load:**
```python
from datasets import load_dataset
ds = load_dataset("Cleanlab/FinQA-hallucination-detection")
# Or load from disk:
from datasets import load_from_disk
ds = load_from_disk("datasets/finqa_hallucination/data")
```

## Reproducing Downloads

To re-download all datasets from scratch:

```python
from datasets import load_dataset
import os

datasets_config = {
    "truthful_qa": ("truthfulqa/truthful_qa", "generation"),
    "halueval_qa": ("pminervini/HaluEval", "qa_samples"),
    "halueval_dialogue": ("pminervini/HaluEval", "dialogue_samples"),
    "halueval_summarization": ("pminervini/HaluEval", "summarization_samples"),
    "sycophancy": ("arianaazarbal/sycophancy_dataset", None),
    "wiki_bio_gpt3_hallucination": ("potsawee/wiki_bio_gpt3_hallucination", None),
    "finqa_hallucination": ("Cleanlab/FinQA-hallucination-detection", None),
}

for name, (hf_id, config) in datasets_config.items():
    ds = load_dataset(hf_id, config) if config else load_dataset(hf_id)
    ds.save_to_disk(f"datasets/{name}/data")
```

## How These Map to Research Questions

| Research Question | Primary Datasets |
|---|---|
| Detecting hallucination (factual errors) | TruthfulQA, HaluEval, WikiBio Hallucination, FinQA |
| Detecting sycophancy (strategic agreement) | Sycophancy Dataset |
| Distinguishing hallucination types | WikiBio Hallucination (severity annotations), HaluEval (task-specific) |
| Probing internal representations | All datasets can be used with activation extraction |
| Context-grounded vs. open-ended errors | HaluEval + FinQA (grounded) vs. TruthfulQA (open-ended) |
